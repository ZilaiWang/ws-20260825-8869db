## 使用通用工具

将元数据写为独立 JSON，参照 examples，所有来源 ID 必须一致。未知 lineage_complete 填 false。只读已完成资产，输出路径不得覆盖正在生成的文件。

```bash
cd evaluation_evidence_audit_20260905
python -m unittest discover -s tests -v
python -m evidence_audit \
  --manifest /absolute/path/to/metadata.json \
  --root /absolute/path/to/read_only_artifact_root \
  --out /absolute/path/to/new_audit_report.json
```

路径参数由现有真实资产确定，不能复制不存在的路径。工具读取模型文件时只计算 SHA，不反序列化。输出 0 不是精度、泛化或部署认证。
