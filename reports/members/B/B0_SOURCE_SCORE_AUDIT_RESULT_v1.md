## 2. B0 审计范围

B0 只做诊断，不训练模型、不改变预测、不选择部署阈值。候选按以下维度统计：

- fold；
- `group_id` 来源组；
- 预测细类；
- 候选框短边尺寸；
- score 区间。

正式错误分解严格复用官方评估器和已有互斥层级：

`TP -> FP_DUP / FP_CLS / FP_LOC / FP_BG`，以及
`FN_CLS / FN_LOC / FN_MISS`。

## 3. 主要结果

### 3.1 分数分布

| score 区间 | 候选数 | 占全部候选 |
|---|---:|---:|
| 0.001--0.01 | 26,699 | 48.1% |
| 0.01--0.03 | 3,882 | 7.0% |
| 0.03--0.051 | 1,097 | 2.0% |
| 0.051--0.10 | 1,033 | 1.9% |
| >=0.10 | 22,837 | 41.1% |

在探索工作点 `0.051` 以下共有 31,678 个候选，占 57.0%。因此“提高候选下限”
不是没有空间，但其中大部分可能是背景，必须先做官方匹配和来源/难度分层，不能
直接全部放回最终预测。

### 3.2 尺寸分布

| 候选框短边 | 候选数 | 低于 0.051 | 达到 0.051 |
|---|---:|---:|---:|
| <32 px | 21,326 | 20,058 | 1,268 |
| 32--64 px | 11,436 | 6,488 | 4,948 |
| 64--128 px | 17,713 | 3,860 | 13,853 |
| 128--256 px | 4,784 | 1,115 | 3,669 |
| >=256 px | 289 | 157 | 132 |

小于 32 px 的候选中只有约 5.9% 达到 `0.051`，说明小目标确实存在显著的低分
集中现象。但这只是候选分布，不等于小目标 Recall 已经可以通过重排恢复。

### 3.3 官方工作点错误结构

`score=0.051` 的正式 OOF 诊断结果：

| 错误类型 | 数量 |
|---|---:|
| FP_BG | 3,303 |
| FP_CLS | 1,115 |
| FP_DUP | 187 |
| FP_LOC | 66 |
| FN_CLS | 1,115 |
| FN_MISS | 553 |
| FN_LOC | 66 |

其中：

- 舰船：`FP_BG=1125`，`FN_MISS=233`；
- 飞机：`FP_BG=1844`，`FN_CLS=1002`；
- 车辆：`FP_BG=334`，`FN_MISS=147`。

错误分解满足计数守恒：

```text
187 + 1115 + 66 + 3303 = 4671 FP
1115 + 66 + 553 = 1734 FN
```

注意：`FP_BG` 的含义是“经过重复、细类冲突和定位规则后仍未归因的预测”，
不是人工确认的纯背景。必须先抽检，不能直接用于背景训练。

### 3.4 折间稳定性

探索工作点的 pooled 结果：

| fold | Recall | FDR | 车辆 Recall | 车辆 FDR |
|---:|---:|---:|---:|---:|
| 0 | 0.8980 | 0.2136 | 0.7068 | 0.6210 |
| 1 | 0.9388 | 0.1579 | 0.5373 | 0.6108 |
| 2 | 0.9149 | 0.2160 | 0.6074 | 0.6150 |

折间 FDR 漂移仍然存在，fold 0 和 fold 2 在统一探索阈值下超过 0.20。这支持
“来源/视觉域存在校准漂移”的研究动机，但不能直接说明某一个来源组造成了漂移。

## 4. 当前结论与下一步

### 已证实

1. M1 候选分数高度偏向两端，低于 `0.051` 的候选占 57.0%；
2. `<32 px` 小候选占全部候选约 38.4%，其中绝大多数低于 `0.051`；
3. 车辆在正式工作点仍是候选不足和背景误检共同最严重的大类；
4. 舰船背景 FP 和飞机细类混淆分别是大类级主要风险；
5. 三折工作点指标存在明显漂移，值得继续做 cross-fit 来源/难度分析。

### 尚未证实

- 低分候选中有多少是真正的未匹配 GT；
- 哪些来源组的低分候选是真目标比例最高；
- 来源组/尺寸重排是否能在固定预算下带来净 Recall 增益；
- `FP_BG` 中有多少是 clear background。

### 下一步 B1

按本阶段执行合同，下一步只做离线重排对照：

1. 全局 score 基线；
2. 来源组 cross-fit 分位数标准化；
3. 来源组+尺寸段的收缩标准化；
4. 固定每图候选预算，重新使用官方 evaluator 比较 pooled 和 official macro。

只有在至少 2/3 fold 同方向、FDR 不恶化且收益不集中于单一来源组时，才将该规则
交给 A 做正式 outer-fold-pure replay。
