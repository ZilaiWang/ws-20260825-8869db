# P03-02 tight crop 全量微调验收与分辨率决策

## 1. 结论先行

P03-TASK-02 的 6 个正式 run 和回传产物通过验收。当前 clean GT-crop 普通分类上限已经很高：`tight-224` 和 `tight-336` 的三折 mean macro recall 分别为 0.9703 和 0.9753。

本阶段冻结 **`tight-224` 为唯一工程工作点**，P03-3 不再继续 336。原因不是 336 没有任何增益，而是它的增益小、折间不稳定、配对区间包含 0，且没有改善最小原生对象；同时 224 的吞吐更高、校准更好，更符合后续对象头和 RTX 3090 端到端预算。

## 3. 对服务器回报的校正

| 回报说法 | 验收后的准确说法 |
| --- | --- |
| 6 折均触发早停 | 只有 5/6 提前停止；`336-fold2` 实际跑满 30/30 epoch，最优为 epoch 27 |
| fold1 在两个分辨率下都最难 | 224 最低是 fold0（0.9615）；336 最低才是 fold1（0.9739） |
| 336-fold1 在 epoch 20 触发早停 | epoch 20 是最优 checkpoint，训练在 epoch 28 才因 patience 停止 |
| 微调证明“ImageNet 表征只需遥感域适配” | 可证明“ImageNet 初始化 + 完整标注监督微调能达到强 clean-crop 上限”；不能将收益全部归因于原始表征或简单域适配 |

上述校正不改变 6 个 best checkpoint 的指标有效性。

## 4. 主结果

### 4.1 三折等权汇总

| 条件 | macro recall | macro F1 | accuracy | aircraft20 macro R |
| --- | ---: | ---: | ---: | ---: |
| tight-224 | 0.9703 ± 0.0078 | 0.9709 ± 0.0054 | 0.9797 ± 0.0010 | 0.9843 ± 0.0037 |
| tight-336 | 0.9753 ± 0.0012 | 0.9761 ± 0.0046 | 0.9807 ± 0.0048 | 0.9867 ± 0.0043 |

336 的三折 mean macro recall 高 0.005059，只比预注册 0.005 近似并列线多 0.000059。这个边界差不应被解读为稳定定律。

### 4.2 单折方向

336 减 224 的 macro recall 差为：

| fold | macro R 差 | macro F1 差 | accuracy 差 |
| ---: | ---: | ---: | ---: |
| 0 | +0.01475 | +0.00701 | -0.00143 |
| 1 | -0.00240 | +0.00270 | -0.00113 |
| 2 | +0.00283 | +0.00588 | +0.00541 |

macro recall 为 2/3 折正向，accuracy 仅 1/3 折正向。fold0 的大差同时受 HM 和 LQS 极小 support 影响：336 分别多分对 1 个样本，即贡献 +0.2000 和 +0.0909 的单折 recall 变化。这正是 macro 指标对真实小样本尾类敏感的体现，也是不能只看四位小数排名的原因。

### 4.3 同对象 OOF 配对

| --- | ---: |
| 两者都对 | 20,328 |
| 仅 224 对 | 180 |
| 仅 336 对 | 199 |

按 4,481 个 `source_image_id` 聚类、10,000 次配对 bootstrap：

- macro recall 差 95% 区间：`[-0.00116, +0.01078]`；
- accuracy 差 95% 区间：`[-0.00136, +0.00312]`；
- 两个区间都包含 0。

该 bootstrap 只反映当前已训练模型在 OOF 对象上的抽样不确定性，不包含重训 seed 方差，因而不能当作完整模型显著性检验。

## 5. 错误结构

### 5.1 官方相关大类

| 子集 | 224 accuracy | 336 accuracy | 净对象差 | 224 macro R | 336 macro R |
| --- | ---: | ---: | ---: | ---: | ---: |
| ship4，2,682 | 0.9381 | 0.9389 | +2 | 0.8995 | 0.9164 |
| aircraft20，17,849 | 0.9858 | 0.9870 | +21 | 0.9843 | 0.9864 |
| vehicle1，402 | 0.9851 | 0.9751 | -4 | 0.9851 | 0.9751 |

336 的舰船 macro recall 提升看起来较大，但以自然 support 计数时舰船只净多对 2 个对象；原因是 HM/LQS 各多对 1 个就会明显改变四类等权 macro。这一诊断有助于保护小样本类，但不能冒充官方端到端收益。

### 5.2 头中尾和具体类

| 频率层 | 224 macro R | 336 macro R | 差 |
| --- | ---: | ---: | ---: |
| tail，9 类 / 3,044 对象 | 0.9562 | 0.9683 | +0.0121 |
| middle，8 类 / 6,314 对象 | 0.9761 | 0.9721 | -0.0041 |
| head，8 类 / 11,575 对象 | 0.9819 | 0.9847 | +0.0028 |

最大正贡献包括 HM `+0.0588`（1 个对象）、LQS `+0.0333`（1 个）、A1_SU-35 `+0.0213`（净 +28 个）和 MS `+0.0115`（净 +23 个）。主要退化为 QHS `-0.0359`（净 -23 个）、A19_SU-34 `-0.0139`（净 -13）和 FSC `-0.0100`（净 -4）。QHS/MS 与 SU-34/SU-35 的两个方向交换说明 336 不是简单地把所有近邻类拉开。

### 5.3 原生像素尺度与边界

| 子集 | 224 accuracy | 336 accuracy | 336 差 | 224 macro R | 336 macro R |
| --- | ---: | ---: | ---: | ---: | ---: |
| 原生短边 <48 px，1,543 | 0.9663 | 0.9527 | -0.0136 | 0.8682 | 0.8588 |
| 48–96 px，11,553 | 0.9787 | 0.9805 | +0.0018 | 0.9749 | 0.9732 |
| >96 px，7,837 | 0.9838 | 0.9862 | +0.0024 | 0.9713 | 0.9804 |
| 源图边界风险，933 | 0.9357 | 0.9368 | +0.0011 | 0.9489 | 0.9600 |

更大输入没有改善最小原生对象，反而在 `<48 px` 子集明显退化。这与 P0-1 的 token 可见性结论一致：resize 可增加网格数，但不会生成原图没有的部件证据。

## 7. 阶段解释

P03-1 的 tight-224/336 linear probe macro recall 为 0.8637/0.8662；微调后为 0.9703/0.9753，绝对增量约 +0.1065/+0.1091。这支持：

1. 普通 ConvNeXt-Tiny 已是很强的 clean crop 基线；后续 DINOv2/扩散特征必须在相同 fold、crop、分辨率和适配公平性下超过它。
2. 对象区域已知时，大部分细类具有充足可分性；后续系统中的主要风险更可能来自真实 proposal 偏移/截断、背景 FP、重复对象和跨域分布。
3. 20,933 个 GT crop 的 0.97 不等于“小样本问题已解决”。HM/LQS 的折间敏感、当前划分的探索性、无背景样本和无真实检测误差，仍是必须保留的边界。

## 8. P03-3/P03-4 准入计划

下一批服务器任务只使用 `tight-224`，顺序为：

1. 对 `sqrt_inverse` sampler 做 3 fold 全量微调；
2. 用已有 natural 的 3 个 checkpoint 对同 fold `jitter_light-224` 做 eval-only；
3. 用新的 `sqrt_inverse` 3 个 checkpoint 做同样 jitter eval-only；
4. 回传 3 个训练 run + 6 个评估 run 的原始 logits和对象预测，再在本地按 `annotation_uid` 配对。

P03-3 保留 `sqrt_inverse` 需同时满足：

- 三折 mean macro recall 有正向收益，且至少 2/3 折同向；
- tail 收益不只是 HM/LQS 各一个对象造成的小 support 幻觉；
- head、ship/aircraft/vehicle 自然 support accuracy 和 pooled overall accuracy 无不可接受退化；
- clean 收益不以明显更差的 jitter 鲁棒性为代价。

若收益小且方向不稳定，按简单性原则保留 natural sampler。P03-3/4 不会重新打开 336、context 或新骨干网格。

## 9. 复现产物

本地复算命令：

```bash
PYTHONPATH=src .venv/bin/python scripts/analyze_p03_results.py \
  --stage fine_tune \
  --runs-root outputs/P03-TASK-02 \
  --manifest outputs/P0-2-exploratory-crop-manifest/crop_manifest.csv \
  --output-dir outputs/P03-TASK-02/local_analysis
```

`local_analysis/` 保留完整性报告、单折/条件汇总、配对比较、聚类 bootstrap、单类、头中尾、边界/尺度子集、混淆对和对象稳定性表。其中 226 个对象在两个微调模型下均错，379 个只有一个模型分对，20,328 个两者均对。
