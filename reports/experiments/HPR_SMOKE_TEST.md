# HPR CUDA 冒烟验证

日期：2026-07-19。该记录只验证代码和轻量性，不代表训练后精度或官方时延。

## 环境

- Python 3.12.7
- PyTorch 2.5.1
- CUDA build 12.1
- NVIDIA GeForce RTX 4060 Laptop GPU

## 结果

- 参数量：72,329；
- 前向输出：25 类细 logits 与 3 大类 logits；
- class-balanced focal/LDAM/层次/原型组合损失可完成反向传播；
- EMA 原型可按 batch 标签更新；
- HPR checkpoint 可保存、重新加载并接入检测适配器；
- 真实标注框可生成 `128×128` RGB 裁剪；
- 适配器冒烟样例成功把低置信度飞机细类 4 重判为同大类细类 5，高置信度候选不变。

未训练网络的纯 HPR FP32 前向测速（20 次预热、100 次计时）：

| Batch | 每批耗时 | 每框折算 |
|---:|---:|---:|
| 1 | 2.958 ms | 2.9576 ms |
| 32 | 3.440 ms | 0.1075 ms |
| 128 | 11.152 ms | 0.0871 ms |

裁剪、检测器、切片、NMS 和序列化不在上述数字内；官方结论必须使用完整 pipeline 的
p50/p95，且参考设备为 RTX 3090，不能用本表代替。
