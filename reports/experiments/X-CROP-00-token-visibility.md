# X-CROP-00 对象尺度与表征网格几何可见性

## 1. 结论摘要

本实验是“几何表征分配/架构瓶颈审计”。全量统计了 20,933 个 bbox，其中 20,000 个无审计标记，807 个贴边但未越界，126 个有微量越界标记；所有框都保留并分层汇总。

当前建议：

- 教师输入优先做 object crop probe，但不宣称整 tile 教师无效。
- crop 首轮使用 224 和 336 两档；224 是成本基线，336 是高表征预算对照，最终选择交给 P0-3/P0-4 精度和成本实验。
- 上下文首轮保留 tight 和 1.25x，1.5x 先延后。本实验只能量化主体稀释和 padding，不能判断上下文的语义价值。
- 在当前训练数据尺度分布下，车辆在所有 tile 场景中都是 `vit_p14` 网格约束的重点风险组；这些场景仍需结合真实检测、tile 截断和时延实验，不直接禁用。

## 2. 证据边界与数据校验

直接观测证据是当前训练集审计表中的 bbox 像素尺度、图像尺寸、类别和边界标记。派生证据是按固定 resize/crop 公式计算的输入像素跨度和 feature-grid 跨度。“未来 10K 测试图与当前数据的原生目标像素尺度近似可迁移”只是待验证假设。

| --- | ---: | ---: | ---: | ---: |
| ship | 2,682 | 32.0 | 98.0 | 240.0 |
| aircraft | 17,849 | 48.0 | 86.0 | 159.0 |
| vehicle | 402 | 20.0 | 37.0 | 54.0 |

数据校验已确认：annotation_uid 全部唯一，所有 image_uid 成功连接，25 个细类与 `rsdet.data.xh_dataset` 的大类映射一致，宽高均为有限正数，且像素宽高与归一化标注反算一致。

## 3. 计算口径

tile 场景假设目标完整位于固定 tile canvas：`s=I/T`，`w_in=s*w`，`h_in=s*h`。该部分不重复模拟 overlap 和 tile 边界截断。

crop 场景以 bbox 中心为中心，使用不缩短的名义方窗：`L=context*max(w,h)`，`w_out=R*w/L`，`h_out=R*h/L`，超出原图时 padding 到 L 后直接 resize。

对 step/patch 为 r 的表征，主指标是短边连续跨度 `min(w_out/r,h_out/r)`，而不是易被细长 HBB 高估的面积。分档固定为 `<2`、`[2,4)`、`[4,8)`、`>=8`，它们是预注册工程代理，不是准确率或模型能力定律。`diffusion_s8` 与 `vit_p14` 的数值不能横向解释为同等能力。

## 4. 主要结果

参考 tile 为 `1280 -> 1024`，参考 crop 为 `224 / 1.25x`，高分辨率 crop 为 `336 / 1.25x`。“放大”只增加网格分配，不增加原图已有信息。

| macro | tile vit14 P50 | tile `<4` | crop224 vit14 P50 | crop224 `<4` | crop336 `>=8` |
| --- | ---: | ---: | ---: | ---: | ---: |
| ship | 5.60 | 28.4% | 6.79 | 12.9% | 69.5% |
| aircraft | 4.91 | 26.1% | 11.08 | 0.0% | 100.0% |
| vehicle | 2.11 | 98.5% | 9.96 | 1.0% | 96.0% |

从参考 tile 转为参考 crop 后，`vit_p14 <4` 风险在舰船、飞机、车辆上分别下降 15.5、26.1 和 97.5 个百分点。因此满足“至少一个大类显著改善、且任一大类均不恶化”的预注册 probe 准入条件。

### 4.4 等价场景

`640 -> 640`、`800 -> 800`、`1024 -> 1024` 和 `1280 -> 1280` 的缩放因子都为 1，因此完整目标的像素/网格跨度在 P0-1 中完全等价。tile 尺寸对上下文、tile 数和截断概率仍有影响，但不属于本指标。

`224 / 1.0` 与 `336 / 1.5` 的主体缩放比也相同。实现已用 `resolution/context` 的唯一比率计算网格跨度，并通过逐元素等价性测试，避免浮点运算顺序使边界样本误分档。

## 5. 不能由本实验宣称的结论

- grid 跨度 `>=8` 不等于一定能细分类，`<2` 也不等于一定检测失败。
- crop 放大是表征分配增益，不是超分，不会恢复原图未观测到的部件。
- HBB 对旋转飞机/舰船包含大量背景，bbox 网格跨度是真实前景结构分配的上界代理。
- feature step 不等于感受野。
- P0-1 不回答扩散是否优于 DINOv2、最优时间步/层、最终 tile 和官方 Recall/FDR。

## 6. 后续执行准入

1. P0-3 用 GT crop 比较 tight/1.25x 和 224/336，同时报细类精度、宏平均、吞吐和显存。
2. P0-4 对比普通 crop classifier、DINOv2 教师和扩散特征教师；本报告只用来固定它们的输入候选。
3. 最终 tile 需联合独立的截断仿真、真实检测指标以及 10K/RTX 3090 端到端时延，不得由本表单独选定。
4. 当教师架构确定时，更新 `representations` 并重跑本实验；不直接沿用通用 `/8` 假设。
