# R1-6 飞机对象头后重排 NMS 实验结果（2026-08-14）

## 1. 结论

R1-6 通过全部预注册门禁，作为下一步端到端流水线的保留候选：

- 仅对 20 个飞机细类执行同类 NMS；
- IoU 固定为官方飞机匹配门槛 `0.50`，不由当前 OOF 调参；
- 统计 TP/FN 和 pooled/macro Recall **完全不变**；
- FP 由 `3329` 降至 `2482`，减少 `847`；
- pooled FDR 由 `0.1460152` 降至 `0.1130649`；
- macro FDR 由 `0.2009748` 降至 `0.1557939`；
- 飞机 pooled FDR 由 `0.1102436` 降至 `0.0689220`；
- 飞机 macro FDR 由 `0.1293468` 降至 `0.0728707`；
- 舰船和车辆所有指标严格相同。

这是 R1 系列目前幅度最大、代价最小的增益。但它仍是同一正式 OOF
上的迭代开发证据，`formal_admission=false`；必须在完整 tile/global 流水线和
后续独立结果上再确认。

## 2. 为什么原检测 NMS 不够

M1 检测器先根据原始细类执行 NMS，R1 飞机对象头随后才会重新分配飞机细类。
因此，两个原先分属不同细类、不会互相压制的重叠框，可能在对象头重排后成为
同一细类的重复输出。加上官方的重复框会计为 FP，原检测 NMS 不再能代表最终
类别空间的唯一对象决策。

R1-6 的位置固定为：

`M1 候选 → 飞机 CE+D4 对象头 → 冻结 C2 校准/阈值 → 飞机同细类 NMS`。

它不修改 score、类别或坐标，只在同图、同飞机细类内按 score 降序保留框，
当两框 `IoU > 0.50` 时压制低分框。舰船和车辆通过 allowlist 结构性旁路。

## 3. 冻结协议

| 项目 | 冻结值 |
|---|---|
| 基线 | `R1-1 CE + full D4 + frozen C2` |
| 作用类别 | category id `4..23` |
| 算法 | 确定性 greedy class-aware NMS |
| 固定 IoU | `0.50` |
| 平分打破 | 原预测顺序 |
| 跨类压制 | 禁止 |
| 外层三折 | 只作阈值稳定性审计，不决定部署阈值 |
| 实验性质 | `iterative_oof_development` |

外层三折在候选集 `1.0/0.9/0.8/0.7/0.6/0.5` 上分别用另外两折做敏感性
审计，三次都独立选回 `0.50`，且其合并预测与直接固定 `0.50` 逐条相同。

| TP | 19470 | 19470 | **0** |

## 5. 错误分解

| 错误 | 前 | 后 | 变化 |
|---|---:|---:|---:|
| FP_DUP | 750 | 104 | **-646** |
| FP_CLS | 777 | 777 | 0 |
| FP_LOC | 62 | 62 | 0 |
| FP_BG | 1740 | 1539 | **-201** |
| FN_CLS | 777 | 777 | 0 |
| FN_LOC | 62 | 62 | 0 |
| FN_MISS | 624 | 624 | 0 |

`FP_BG` 是守恒分解中“无法归因的剩余 FP”，不等价于人工确认的纯背景。
其减少说明同类重叠的虚警也成簇出现，被保留的高分框没有成为 TP 时，其余低分框
会落入 `FP_BG`，因此会同时被后 NMS 清理。

## 6. 准入判断

预注册的八项门禁全部通过：官方 pooled 门槛、pooled/macro Recall 安全、
pooled/macro FDR 改善、FP_DUP 降幅、ship/vehicle 精确旁路和 cross-fit 对固定阈值的
三折确认均通过。

科学状态为 `scientific_admission=true`，但不直接宣告比赛测试集收益：

1. 当前 OOF 已用于多次研发决策；
2. 真实 10K 切片可能增加跨 tile 重复，收益可能更大，也可能出现更密集的
   同类真实目标；
3. 同类相邻真实目标的框若 `IoU > 0.50`，理论上仍可被 greedy NMS 误压制。

因此下一步只需把该操作接入完整管线做回归，不需要继续搜 NMS 网格。
