## 2. 已跑完的实验与结论(三创新评估全景)

### 2.1 创新对比排序: Y5 > Y4 > Y3

| 模型 | 方法 | 最优工作点(Rec/FDR) | 结论 |
|---|---|---|---|
| M1 | YOLO26s 基线 | t=0.05: 0.917/0.196 | 基线 |
| **Y5-ROT90** | +90° 旋转增强 | t=0.1: **0.921/0.157** | **最终链基座** |
| Y4-AFSS | 充分度采样 | t=0.1: 0.897/0.177 | 达标但全弱于 Y5 |
| Y3-HIER | 层次粗细类损失 | t=0.7: 0.853/0.157 | 少数类塌陷, 不采用 |

- **Y5 选为基座的三条硬证据**:
  1. 阈值曲线 t=0.1 严格双占优 M1;
  2. 专项类零牺牲(HM 0.647 / LQS 0.600 / TU-160 0.371 / F-22 0.870,
     全部持平或优于 M1);
  3. paired 净增 888 GT(找回 1,020 个 M1 漏检, 只丢 132 个)。

### 2.2 为什么 Y3 失败(重要教训)

- 层次损失让分数分布**两极化**: 62 万候选(11.2× M1), 低分噪声堆在 0-0.1,
  真阳尾巴拖到 0.35 以下;
- 为了 FDR≤0.20 必须用 t=0.7 高阈值 → **少数类(HM/LQS/TU-160)被系统性误杀**
  (0 / 0 / 2.2%);
- **教训: 训练期方法若破坏分数校准, 再高的 Recall 天花板也白搭**——
  这直接指导我们选择"不改损失、只加数据增强"的 Y5。

## 3. 尚未解决的问题(按对最终指标的影响排序)

### 3.1 N2-CFG 背景门控: ship/vehicle 负样本不足(卡主线)

**问题**: 门控分类器(ForegroundGate)能显著删背景误检(FP_BG 删 12.1% vs
S0 基线 1.2%, g5 paired bootstrap 显著), 但**只对 aircraft 有效**:

| 粗类 | 门控删除率 | 要求 | 判定 |
|---|---|---|---|
| aircraft | 30.7% | - | ✅ |
| ship | 0.14%(1/723) | ≥15% | ❌ |
| vehicle | 2.6%(6/232) | ≥10% | ❌ |

**根因**: 白名单(人工确认的 clear_background 负样本)只有 **33 个**
(ship 13 / aircraft 9 / vehicle 11)——ship/vehicle 的 coarse-conditioned 头
学不到背景模式。已在扩审第 2 批(566 卡, ship 245/vehicle 87 为主),
回传后白名单预计到 ~98, 重训冲刺 g2。

**附带问题 g7**: 门控误删 3 个 fold0 低分边界 TP(score<0.04),
recall_budget=0 的 0 容忍门禁 → FAIL。3 TP vs 删 186 FP_BG 的权衡
是门禁设计问题, 需团队拍板。

### 3.2 三模型全漏 91 个目标(真残余短板, 直接影响 Recall 天花板)

- Y5/M1 双漏 411 个中, M3 能救 320 个(78%);
- **三模型全漏仅 91 个**: ship 43 / aircraft 28 / vehicle 20;
  尺寸: small 47 / tiny 26 / medium 18 —— **80% 是小目标**;
- 结论: 小目标恢复是唯一明确的 Recall 天花板(约 +0.4pp 但难度极高);
- 对接: C 的 P2 小尺度恢复头路线(未跑, 需 2-3 GPU 日)。

### 3.3 细类混淆: 兄弟机型判别弱(影响 Macro Recall 与 FDR)

- M1 混淆基线: 2,228 次细类错配, 高度集中在 aircraft 兄弟机型
  (TU-160→TU-22 222 / SU-35→SU-34 140 / KC-135→E-8 128)+ ship QHS↔MS 194;
- **Y5 仍未解决**(混淆对与 M1 同源)——说明训练期损失/增强对细类判别帮助有限;
- 机会: 细类级阈值校准 / 混淆对配对后处理 / 结构化属性辅助。

### 3.4 稀有类(HM/LQS)仍未达到理想水平

| 类 | GT 数 | Y5 Recall | 目标 |

| HM(军舰) | 17 | 0.647 | ≥0.85? |
| LQS(商船) | 30 | 0.600 | ≥0.85? |

- GT 极少(17/30), 靠数据增强/重采样难; 思路: 度量学习/原型学习/结构化先验;
- 注意: 官方 V1.6 Macro 口径=大类内细类简单平均, **稀有类对 Macro 权重极高**——
  提升 HM/LQS 是 Macro Recall 的最大杠杆。
