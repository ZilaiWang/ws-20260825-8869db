## 5. 本地测试是否有效：分开判断公式、方向和绝对校准

### 5.1 全量权重同源诊断与正式隐藏集

以下本地结果全部使用本次原始full权重与0.536阈值；包装前后12张大图3913框已逐框一致。
但模型已经见过Normal全部4481图，以及Hard/Sentinel各600源图；这些是**训练同源诊断**。

|Normal同源|89.101 / 4.214%|99.015 / 1.417%|85.572 / 6.267%|91.229 / 3.966%|无同口径时延，不填|
|Hard同源|86.500 / 2.888%|99.034 / 2.893%|80.978 / 3.871%|88.838 / 3.217%|84.9648|

|官方隐藏集|80.989 / 6.749%|94.597 / 3.727%|83.158 / 21.000%|86.248 / 10.492%|76.6010|

相对Hard，本次正式舰船Recall低5.511pp、飞机Recall低4.438pp；车辆Recall反而高
2.180pp，但车辆FDR高 **17.129pp**。相对Sentinel，车辆FDR高 **18.297pp**。
这不是“官方在所有维度统一难一些”，而是**车辆负样本风险严重低估、舰船/飞机召回乐观**。

官方比Hard低8.3637分、比Sentinel低8.6774分。把本地时延统一替换成官方3.551833s后，
本地分数反而变成85.1045与85.4394，差距扩大为8.5034与8.8384分。差距是精度与数据问题，
不是官方机器慢。不能通过给所有本地分数统一减8.5分就宣布校准完成。

### 5.2 无泄漏CV3能说明什么

此前P40相对同长度S1024的无泄漏对比：Hard 52.009→58.221（+6.212）；冻结
Sentinel-B 58.200→60.414（+2.214）。本次正式增益+4.468与“有正向候选”一致。
但这只有一次新候选的确认，且CV3是S1024 40e→适配40e，full是160e→适配40e；
CV3逐折阈值与full统一0.536也不相同。不能以数值恰好落在两项增益之间作外推规律。

更重要的是，CV3曾显示三类Recall改善，正式部署却三类Recall均下降：

1. 计分口径已对齐；
2. 候选总分方向获得一次支持；
3. 逐类收益、工作点迁移和绝对分数预测仍未校准好；
4. 同源85分与严格CV3约58–60分都不应直接宣传成正式成绩预估。

已有Background-100MP发现full P40在0.536下10个误检，旧S1024原工作点2个。
该证据仍保留为负向风险；不同背景上的FP密度不等于正式FDR，不能因本次总体FDR下降
就反写成压力测试通过，也不能据10个FP反推出官方背景面积或图数。

## 6. 接口没有提供的内容及推断边界

本次“全部读取”指本队结果页实际返回的全部记录与字段，不是能访问官方隐藏数据集。
当前响应没有：

- 25细类各自的GT/TP/FP/FN及细类PR曲线；
- 逐图预测、逐图GT、原图、框分数、混淆矩阵或错误截图；
- FP_BG / FP_DUP / FP_CLS / FN_MISS等错误分解；
- 测试图数、来源、尺寸、负图数量、密度、地理场景；
- 逐图耗时、GPU型号、实际拉取镜像digest或成功任务运行日志。

不能由两组粗类计数和macro比率唯一反推这些内容。尤其不能以提交到成绩的191秒
除以3.551833秒推算测试图数：前者混有排队、镜像处理、启动、评分等耗时。
车辆支持仅95个GT，1个TP就改变该类Recall约1.053pp；小样本波动要保留，不能把两个
TP的差异夸成稳定大规模统计结论。舰船具体是哪一个细类掉点，接口不足以指认。

## 7. 下一步最有价值的分析顺序（本轮不启动训练或提交）

### 第一优先：区分模型改进与工作点收紧，恢复有效召回

保留v2为已过三门的回退锚点。对旧full与P40既有低阈值预测做**相同后处理、相同工作点**
的配对回放，记录各细类TP/FP/FN和七子分，而不是再比较0.15与0.536的孤立结果。
先查阈值前是否已有正确低分候选：有则优先研究校准/选择性保留；没有则属于候选覆盖、
定位或分类能力问题，才需要新的模型训练。不能只凭本次结果认定“降低阈值必然更好”。

Ship已有较低macro FDR，但macro Recall80.989%、pooled Recall67.419%，是主要
召回突破口。Aircraft FDR仅3.727%，继续拒识收益有限，适合把恢复被删真阳性列为约束。
同时必须检查舰船小support细类，避免恢复召回时重现v1的macro FDR爆炸。

### 第二优先：车辆真实负样本覆盖和置信度排序

正式车辆100个预测中21个FP，既有本地同源Hard/Sentinel仅约3%的FDR，显示负样本
评估不足。优先检查既有真负图/困难背景与部署候选域，而非机械提高车辆阈值：车辆Recall
已低于85%。区分是背景、重复、相邻目标定位还是分类错误；在没有图像证据前不指定某种原因。
仅作尺度说明：如果不损失TP而删除2个车辆FP，FDR就从21/100降到19/98=19.388%；
如果无新增FP救回2个TP，则Recall从79/95恢复到81/95=85.263%。这不是可直接实现的承诺。

### 第三优先：固定两套不同职责的评估，不反复改测试集追榜

继续保留开发配对测试与独立来源确认测试；Normal作为附加诊断，100MP背景作为负样本
压力项，不新增一串难以解释的主榜。阈值只在开发部分确定，确认集不调参。
本次正式结果加入独立外部锚点记录，但不按v2误差重新挑选一个更像v2的Sentinel后再宣布
验证成功。尤其明确：full已见过的“Sentinel”不能再承担full无泄漏确认的职责。

如再训练，优先补齐验证模型与full的训练成熟度/适配预算对应关系，避免将40e外层模型的
统一阈值分布直接当成160e→40e full分布。既有提交是复合变化；下一次尽量只验证一个
有明确独立证据的改变，保留v2镜像和结果，不自动占用剩余机会。

## 8. 离80、85和93分还有多远

当前距80分差3.3990，距85分差8.3990，距93分差16.3990。下面只做公式上限计算，
固定官方时延3.551833s；假设能够独立改变R/FDR，**不是实际模型可达上限或官方预测**。

|假设|公式分数|含义|
|---|---:|---|
|当前Recall不变，三类FDR全变0|85.4154|单靠去虚警仍到不了93|
|当前FDR不变，三类Recall全变1|90.6782|单靠召回也到不了93|
|每个粗类都R=94%、FDR=10%|84.0640|“94%召回”不等于“94分”|
|每个粗类都R=97%、FDR=3%|93.4926|93分需要召回与虚警同时很强|

主判断：P40让我们从“有分但FDR硬门失败”走到“有稳定可用的正式过线结果”。接下来
应利用已经获得的低FDR恢复Ship/Vehicle召回，并补足车辆负样本校准；不是继续无差别
收紧所有类别，也不是把主要算力投入微小的时延节省。
