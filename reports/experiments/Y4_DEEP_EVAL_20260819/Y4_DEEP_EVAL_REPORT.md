# Y4-AFSS 深度评估报告(正式三折, 2026-08-19)

> 数据: Y4-AFSS 三折 OOF 61,390 proposals, 统一评估 + 阈值曲线
> 结论: **Y4 达标(硬门禁)但各方面弱于 Y5, 不进入最终链; 保留为诊断参考**

- 全阈值段 Recall 均低于 Y5 2-4pp, FDR 均高于 Y5 —— **Y5 全面占优**。

## 4. 错误构成(Y4@0.1)

- FP: FP_BG 2,391 / FP_CLS 1,222 / FP_DUP 367 / FP_LOC 51
- FN: FN_MISS 876 / FN_CLS 1,222 / FN_LOC 51
- FN_CLS 1,222 明显高于 Y5(896)——细类判别弱于 Y5。

## 5. 结论

1. **Y4-AFSS 达标但全维度弱于 Y5**: Recall -2.4pp、专项类全低、FN_CLS 高;
2. **不进入最终链**: 充分度采样(per-image suff)相对旋转增强无增益;
3. **保留价值**: AFSS 的 per_image_suff 可作为后续"训练样本充分度"分析的特征,
   与 C 的 P2 小目标恢复结合时参考;
4. 三创新最终排序: **Y5 > Y4 > Y3**, Y5 为最终链基座(决策不变)。
