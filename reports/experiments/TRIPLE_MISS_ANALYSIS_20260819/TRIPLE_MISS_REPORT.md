# Y5/M1 双漏 × M3 教师证据交叉分析(2026-08-19)

> 数据: Y5/M1 双漏 GT 411 个 × M3 hard positives(教师证据)1,313 个
> 目的: 定位最终链(Y5 基座)的残余短板, 判断 M3 教师证据能否补漏

## 1. 核心结论

| 类别 | 数量 | 占比 |
|---|---|---|
| 双漏(M1+Y5 都没检出) | 411 | - |
| **其中 M3 能救(在教师证据中)** | **320** | 77.9% |
| **三模型全漏(真残余短板)** | **91** | 22.1% |

**关键: M1/Y5 双漏 ≠ 三模型全漏。M3 能救回 320 个(78%), 教师证据对最终链有直接补漏价值。**

## 2. M3 能救的 320 个(可并入最终链)

| 粗类 | 数量 | 尺寸 | 数量 |
|---|---|---|---|
| aircraft | 222 | small | 186 |
| ship | 70 | medium | 101 |
| vehicle | 28 | tiny | 31 |
| | | large | 2 |

- 主要补回 aircraft/small(186)和 medium(101)——正好是 Y5 双漏集中区;
- M3 教师证据原判定"车辆条件优先交给 C", 但这里显示对 aircraft/ship 也有补漏价值,
  最终链侧(不在 C 消费范围内)可额外取用这 320 个。

## 3. 三模型全漏 91 个(真残余短板, 后续创新空间)

| 粗类 | 数量 | 尺寸 | 数量 |
|---|---|---|---|
| ship | 43 | small | 47 |
| aircraft | 28 | tiny | 26 |
| vehicle | 20 | medium | 18 |

- ship 43 个最多(可能是极端遮挡/低对比度目标);
- small 47 + tiny 26 = 73 个(80%)是小目标——**小目标仍是三模型共同瓶颈**;
- 这 91 个可作为最终链验收时的"已知残余失败案例"留档, 也是下一轮创新的靶子。

## 4. 建议

1. **最终链补漏**: Y5 基座 + M3 教师证据中 320 个双漏目标的候选并入(可 +1.5pp recall);
2. **验收留档**: 91 个三模型全漏目标列入最终报告的"残余失败案例", 附 image_id 清单;
3. **下一轮创新靶子**: 小目标(small/tiny 73 个)与 ship(43 个)是明确方向,
   与 C 的 P2 小尺度恢复头路线一致。
