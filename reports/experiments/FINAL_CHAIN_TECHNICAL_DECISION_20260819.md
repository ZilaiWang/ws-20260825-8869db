## 2. 为什么选 Y5 作基座（证据链）

### 2.1 阈值曲线（同口径公平对比）

| 阈值 | Y5 R/F | M1 R/F |
|---|---|---|
| 0.001 | 0.974 / 0.688 | 0.932 / 0.649 |
| 0.05 | 0.934 / 0.204 | 0.917 / 0.196 |
| **0.1** | **0.921 / 0.157** | 0.914 / 0.163 |
| 0.2 | 0.906 / 0.117 | 0.907 / 0.132 |
| 0.5 | 0.868 / 0.064 | 0.881 / 0.084 |

- **t=0.1 处 Y5 严格占优**：Recall 0.9211 > M1@0.05 的 0.9173，且 FDR 0.1567 < 0.1964；
- 候选量 65,301（仅 1.18× M1），分数分布健康——**不需要高阈值压噪声，不牺牲少数类**。

### 2.2 专项类（材料 19 点名，Y5@0.1 vs M1@0.05）

| 类 | Y5 Recall | M1 Recall | 判定 |
|---|---|---|---|
| HM（稀有舰船） | 0.647 | 0.706 | 略低但保住 |
| LQS（稀有舰船） | 0.600 | 0.500 | **更好** |
| A6_TU-160 | 0.371 | 0.332 | **更好** |
| A15_F-22 | 0.870 | 0.789 | **更好** |

- 与 Y3 形成鲜明对比：Y3 在同样位置 HM/LQS/TU-160 全塌（0/0/0.022）；
- **Y5 零牺牲少数类**，这是入选的最关键理由。

### 2.3 Paired 互补（低阈值 0.001）

| 类别 | 数量 |
|---|---|
| both（双检出） | 19,370（92.5%） |
| **y5_only（Y5 找回 M1 漏检）** | **1,020（4.87pp）** |
| m1_only（M1 独有） | 132（0.63pp） |
| neither（双漏） | 411 |

- 净增 888 个 GT，Y5 严格覆盖 M1。

## 3. 最终链候选方案（三级增强）

```
最终链 = Y5-ROT90 基座（t≈0.1）
       + M1 独有候选 130 个   [已验证：+0.62pp recall，FDR 不劣化]
       + M3 双漏候选 320 个   [理论：可再 +1.5pp，待正式验证]
```

### 3.1 第一级：Y5 独立（已定）
- 硬门禁达标，Recall/FDR 双占优，少数类全保住；
- 变更风险极低：仅加旋转增强，不改损失/结构/推理。

### 3.2 第二级：+M1 独有候选（已验证，commit 37a63d6）
- 融合实验：recall 0.9741 → 0.9803（+0.62pp / +129 TP），FDR 0.6877 → 0.6864；
- 成本：仅 130 个候选（0.2%），无 FDR 代价；
- 实现：全局聚合阶段合并两模型候选 → 统一阈值/NMS（即 E 的组合系统）。

### 3.3 第三级：+M3 双漏候选（理论收益，待验证）
- 双漏 411 中 M3 能救 320 个（aircraft 222 / ship 70 / vehicle 28；small 186）；
- 理论 recall 可再 +1.5pp，但需验证并入后的 FDR 代价；
- 依赖：M3 教师证据（已交付 C 用，最终链侧可复用同 320 个候选）；
- **待 GPU 空闲跑 E 组合实测后一并评估**。

## 4. 明确不采用：Y3-HIER（保留诊断）

- 决定性缺陷：工作点下 HM/LQS/TU-160 塌陷（0/0/2.2%）；
- Macro Recall 落后 M1 12pp（0.745 vs 0.867），官方 V1.6 排名口径吃亏；
- 候选量 62 万（11.2× M1），分数校准差；
- **保留价值**：低阈值找回 M1 漏检 1,203 个 GT——若未来做"多候选集融合"可
  复用为第三候选源（优先级低于 M3，因其分数分布更差）。
