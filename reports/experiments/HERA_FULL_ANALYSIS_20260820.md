## 二、最深的病根: MS/QHS 的系统性视觉模糊

把每一类错误按"涉及哪些类"横向切开, MS(导弹) 和 QHS(小舰船) 几乎出现在**每一个错误象限**:

| 错误象限 | MS 的排名 | QHS 的排名 |
|---|---:|---:|
| 排序损失 GT(有候选但分数低) | **83(第1)** | 50(第2) |
| 低估真阳(y5_score<0.1) | **366(第1)** | 222(第2) |
| 自信误检(背景 y5_score>0.5) | **396(第1)** | 204(第2) |
| crop 幻觉(背景被判成该类) | **23.4%(第1)** | 15.4%(第3) |
| 细类混淆(FP_CLS) | MS↔QHS **288** | 同左 |

### 2.1 这意味着什么

MS/QHS 存在**内在的视觉模糊性**:

1. **检测器对它们"双向犯错"**: 既把真 MS/QHS 判得不自信(低估真阳 366+222 个), 又把背景判成 MS/QHS 且很自信(自信误检 396+204 个)。这不是"阈值没调好", 而是检测器无法从视觉上稳定区分"真的小导弹/小舰船"与"长得像的背景结构"。

2. **crop 教师同样分不清**: 72% 的背景候选被 crop 教师(ConvNeXt-T)"幻觉"成 MS/FSC/QHS/SU-24 这 4 类(见第三节)。crop 教师对"非大飞机的任何 patch"的默认答案是这 4 个"视觉简单"类。

3. **D4 旋转一致性也对它们失效**(见第四节): 因为误导的背景(跑道标记、规则纹理)和真目标在旋转下都稳定重现, D4 无法区分。

### 2.2 根因推断

MS(导弹)与 QHS(小舰船)在俯视遥感中是"形状简单、尺度小、与地面结构(跑道划线、建筑、车辆)高度同形"的目标。它们的可区分信息不在单框外观, 而在**上下文**(导弹在发射架/跑道特定位置、舰船在水中)。当前证据链(Y5 框 + crop 单框 + OTO + D4)都是"单框/单目标"证据, **缺失上下文证据**, 因此对 MS/QHS 这类"单框不可分"的目标天然失效。

## 三、crop 幻觉机制(背景被判成什么)

### 3.1 全量背景候选(44910 个)的 crop_top1 分布

| 幻觉类 | 占比 |
|---|---:|
| **MS** | **23.4%** |
| **FSC(车辆)** | **18.7%** |
| **QHS** | **15.4%** |
| **SU-24** | **14.7%** |
| (其余 21 类合计) | 27.8% |

**前 4 类合计 72.2%**。crop 教师把近 3/4 的背景 patch 判成 MS/FSC/QHS/SU-24。

### 3.2 这 4 类的共同点

- MS/FSC/QHS/SU-24 都是**尺度偏小、外观简单**的目标(FSC 短边中位 37px 全场最小, SU-24 58px, QHS 81px);
- crop 教师在 M1 proposal 域训练, 部署输入是 Y5 proposal(含大量背景框), **背景 patch 的分布是训练时没见过的**;
- 面对"陌生的小 patch", crop 教师退化为"输出训练里最常见的小目标类", 即 MS/FSC/QHS。

### 3.3 后果

crop 证据(改类、crop_top1/margin/entropy)**天生无法压 FP_BG**——因为背景被 crop 教师"幻觉"成高置信的 MS 等类, 与真 MS 在 crop 特征上不可分。这直接解释了为什么压 FP_BG 只能靠 y5_score/has_oto/d4, 而 crop 特征只服务 FP_CLS 纠错。

## 四、FP_BG 逃过 OER 的深层画像(1899 个)

| 特征 | 值 | 解读 |
|---|---|---|
| y5_score | 中位 **0.071**(p25 0.012 / p75 0.377) | 检测器分数其实**不高**, 但 OER 仍把它们排进工作点 |
| d4_support | **d4=3 占 86%**(1633/1899) | **绝大多数在 4 个旋转方向都稳定重现** |
| has_oto | 18.9% 有支持 | 81% 无 OTO 支持(此特征仍有一定判别力) |
| short_edge | 中位 58.6px | 不小 |
| local_density | 中位 25 | 出现在候选密集区域 |
| 幻觉类 | MS 47.5%(903/1899) | 近一半被 crop 判成 MS |

### 4.1 关键发现: D4 的判别力被"结构化背景"抵消

之前 d4 特征的判别力来自"随机噪声在旋转后消失"。但**工作点里逃过 OER 的 FP_BG, 86% 是 d4=3(4 方向全重现)**——它们是**结构化背景**(机场跑道划线、规则纹理、建筑边缘), 不是随机噪声。旋转后这些结构依然存在, 检测器依然检出。因此 d4 对这些"最难啃"的背景误检**几乎无判别力**, d4 能压掉的只是"旋转不稳的随机噪声"那部分(已经在低分数段被 y5_score 自然压掉了)。

### 4.2 局部密度线索

FP_BG 的 local_density 中位 25(高于背景整体), 说明它们**集中在真目标密集的区域**——可能是"真目标附近被连带检出的背景结构"(跑道上的飞机附近、停机坪的标记)。这提示这部分 FP_BG 与真目标存在空间关联。

## 五、检测器的双向系统性偏差

### 5.1 高估背景(自信误检)

- 4.1% 的背景候选 y5_score>0.5(1856 个);
- 这些"自信误检"的类别: **MS 396 / QHS 204 / E-8 142 / SU-34 117**;
- 即检测器把"背景结构"自信地判成 MS/QHS 等小目标类。

### 5.2 低估真阳

- 8.7% 的真阳候选 y5_score<0.1(1769 个);
- 这些"低估真阳"的类别: **MS 366 / QHS 222 / TU-160 190 / FSC 144 / KC-135 106**;
- 即检测器对真的 MS/QHS/TU-160 不自信。

### 5.3 结论

检测器存在**类别先验偏置**: 对 MS/QHS 这类"小目标"类, 它在"看到类似形状时"倾向高置信输出(误检), 但"看到真的这类目标时"又低置信(漏检)。这是同一病根的两面——**MS/QHS 的类内-类间边界在检测器特征空间里是模糊的**。

## 六、FP_CLS 的兄弟机型混淆结构(841 个工作点)

改类后仍错的 FP_CLS 有 2171 个(全量), 混淆高度结构化:

| 家族 | 混淆对 | 数量 |
|---|---|---|
| 轰炸机 | TU-22 → TU-160 | **347** |
| 舰船 | MS ↔ QHS | 161 + 127 = **288** |
| 苏霍伊 | SU-35 ↔ SU-34 / SU-24 | 119+63+59+36 = ~277 |
| 预警/加油 | E-8 ↔ KC-135 | 114 + 59 = 173 |
| F 系列 | F-15 ↔ F-16 / F-22 | 55+54+65 = ~174 |

### 6.1 根因

这些混淆是**"flat 25 类 softmax"的固有缺陷**: 兄弟机型之间的区分特征(翼型、垂尾数量、发动机布局、预警盘)在扁平 softmax 里被"平均"掉了, 网络只能靠"整体外观相似度"判类, 因此外观接近的兄弟机型必然大量混淆。crop 教师同样受此限制(改类只救回 85%)。

## 七、类不平衡与数据域多样性

### 7.1 类不平衡(25 类 GT 数)

| 尾部类 | GT 数 | 头部类 | GT 数 |
|---|---:|---|---:|
| HM | **17** | FA-18 | 2147 |
| LQS | 30 | MS | 1994 |
| KC-10 | 262 | KC-135 | 1424 |
| TU-160 | 361 | SU-35 | 1317 |
| FSC | 402 | C-130 | 1297 |
| E-8 | 432 | — | — |
| F-22 | 493 | — | — |

**HM(17)与 FA-18(2147)相差 126 倍**。HM/LQS 是"极小样本类", 检测器对它们的表征几乎无法学习, 这也是此前 E6(重点类原型)无增量的根因之一。

### 7.2 数据域多样性

255 个 source_group(全部为 `mar20-airport-proxy-XXX`), 即数据来自 **255 个不同的机场/代理场景**。最多的是 mar20-airport-proxy-051(1525 个对象)。这意味着:

- 模型需要在 255 个不同机场、不同成像条件、不同 GSD 下泛化;
- MS/QHS 的"视觉模糊"很可能是**域相关的**——某些机场的跑道标记/建筑恰好长得像导弹/舰船, 导致该域内 MS/QHS 误检集中。

## 八、排序损失 322 GT 的根因

排序损失(有候选但 frontier 够不到)的类分布: MS 83 / QHS 50 / FSC 40 / SU-35 27 / TU-160 27 / KC-135 18。

这些 GT 的共同点是**检测器低自信**(y5_score<0.1 的真阳里 MS 366/QHS 222/TU-160 190/FSC 144)。它们不是"候选缺失"(有候选), 而是"候选分数低, 被背景 FP 挤到 frontier 之外"。

结合第五节, 排序损失的本质是: **检测器对 MS/QHS/TU-160/FSC 这 4 个"低自信类"的系统性低估**, 导致它们的候选分数天然低于背景误检(MS/QHS 的自信误检), 在固定 FDR 前沿上被挤出。

## 九、三条深层根因链(总览)

```
【根因 A】MS/QHS 视觉模糊(单框不可分)
   ├─ 检测器低估真 MS/QHS(漏检/排序损失)
   ├─ 检测器自信误检背景为 MS/QHS(FP_BG)
   ├─ crop 幻觉背景为 MS/QHS(改类失效 + crop 压不了背景)
   └─ MS↔QHS 细类混淆(FP_CLS)
   → 贯穿排序损失/FP_BG/FP_CLS 三大错误, 是唯一贯穿性病根

【根因 B】crop 教师域偏差
   └─ M1 域训练 → Y5 proposal 域部署, 背景 patch 陌生 → 72% 背景幻觉成 4 个简单类
   → 直接封死了"用 crop 证据压 FP_BG"这条路

【根因 C】证据链缺失上下文
   ├─ D4 对"结构化背景"失效(86% 稳定重现)
   ├─ 所有证据都是单框/单目标(Y5/crop/OTO/D4)
   └─ MS/QHS 的可区分信息在上下文(位置/场景), 不在单框
   → 解释为什么 0.9620 之后继续靠"加单框证据"收益递减
```

这三条根因链说明: 当前 0.9620 的剩余误差(FP_BG 1899 + FP_CLS 841 + 排序损失 322)**不是分散的孤立问题, 而是三个系统性根因的投影**——其中 MS/QHS 视觉模糊是最核心的一条。
