# E9: P2-lite 停止决策(2026-08-20)

## 决策依据(两条独立证据链)

### 1. Y2 快筛结论(2026-08-11, Y2_FAST_SCREEN_RESULT)
- 完整 P2(stride-4 通路)在 fold0 40ep 快筛:
  - 低阈值候选 +36.1%, 但**无候选 vehicle GT 5/133 零变化**;
  - 进入可用置信度区间后 overall Recall −5.84pp / macro Recall −10.19pp;
  - 已冻结决策: "不启动 P2-Lite, 因为完整 P2 没有可保留的 unique-vehicle 净增益"。

### 2. E10 SAHI 诊断(2026-08-20, 本批次)
- 82 个"完全无候选"GT(含 QHS 36/FSC 20/TU-95 14)在 2× 放大后仅救回 6(7%);
- 76/82 是检测器**硬盲区(低对比度/场景盲区), 非尺度问题**;
- 结论: 增加 P2 小目标头/切片放大都救不回特征层缺失的目标。

## 结论

E9 保持**停止状态**(与 Y2 决策一致)。小目标恢复的可行路径:
1. 训练期难例挖掘(E7 困难课程已实现 --hard-curriculum);
2. 数据级合成/增强(不在本次范围);
3. 已知残余失败案例留档(82 目标, /tmp/sahi_gt_targets.json)。

不投入 GPU 预算到 P2 头改造(完整 P2 已证无效, P2-lite 是同一机制的减量版,
无独立价值)。
