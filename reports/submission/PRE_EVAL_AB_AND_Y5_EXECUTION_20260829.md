# 预测评线上差距诊断、切片融合 A/B 与 Y5 部署准入（2026-08-29）

## 1. 结论先行

线上 `trial-v1.0` 的 M1 fold0 原始 Docker 得到 pooled Recall `0.8022`、FDR
`0.2078`、平均时延 `2.3318 s`。本轮建立了两张 10000×10000、共 910 个 GT、
覆盖全部 25 细类的折外伪大图。原始 T0 在该诊断集得到 Recall `0.8099`、FDR
`0.2449`，Recall 与线上仅差 `+0.0077`，错误方向一致，因此足以用于部署变量配对，
但不得把它当作独立泛化验证集。

部署侧得到四个可执行结论：

1. `global` 聚合存在低分证据和跨细类投票改变最终对象的风险，不再作为正式默认值；
2. 安全融合 T3 在相同 FDR≈0.20 时把 M1 Recall 从 T0 的 `0.7901` 提升到
   `0.8165`，净增 `+0.0264`；
3. FP16→FP32 与 `max_det 500→1500` 的预测和指标实质相同，停止这两条路线；
4. 净化后的 Y5 fold0 + T3 在相同 FDR≈0.20 时达到 Recall `0.8330`，比
   M1+T3 再高 `+0.0165`，成为当前优先候选。

## 2. 冻结输入

- M1 fold0：SHA256 `d403ca0d5f760f8d7271af33c467426a3bd8ce8095b6d13e5dc63a6d8e19501d`；
- Y5 fold0 原训练权重：SHA256 `47d98fab29cbc4b6836a907a77cda33294affbd891e90f9e3aab0b05578e7c96`；
- Y5 fold0 净化权重：SHA256 `65c62b20f48e386f6c909c2ad0ad9daa7ed8cda6d7fbe4a2d54953b25c0adaac`；
- 伪大图来源：正式 CV3 fold0 的 200 张未见图像；每张伪大图使用 100 张；
- 配对协议：同图、同 GT、同权重（模型对比项除外）、同官方 prediction-first matcher。

Y5 净化只执行以下操作：采用 EMA/模型参数、冻结参数、恢复赛事 25 类名称，删除
optimizer、scaler、随机数和 Albumentations 训练对象。未进行训练、微调或参数融合。
净化前后在同一张 10000×10000 图、`imgsz=1024/conf=0.001/max_det=500/FP16`
下均输出 500×6 张量，逐元素最大绝对误差为 `0.0`，因此通过 bit-exact 等价门禁。

优先；最终标签、置信度与 bbox 必须来自同一个真实候选。

| M1 T4 | 0.346 | 0.8132 | 0.2000 | 0.7889 | 0.1661 |
| Y5 T3 | 0.221 | **0.8330** | 0.1996 | **0.8166** | 0.1736 |

Y5 T3 在 FDR≤0.17 时的伪大图工作点约为阈值 `0.296`、Recall `0.8231`、
FDR `0.1678`。由于伪大图的接缝与灰色 padding 会抬高 FP，阈值只用于候选排序，
不能直接替代正式 OOF 和线上校准。
