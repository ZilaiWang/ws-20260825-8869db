# XH-202625 数据集详细说明

本文描述当前收到的 `data/` 目录及已由官方问答确认的评测规则。数量和统计值来自对现有 4,481 张图像与 4,481 个标签文件的完整读取，不包含外部数据，也不把正式测试集尚未发布的属性当作已知事实。

## 1. 检测任务

检测器需要对遥感图像中的目标输出水平边界框和 25 类中的一个细分类别。类别由三部分组成：

- 舰船：4 类，ID `0–3`；
- 飞机：20 类，ID `4–23`；
- 发射车：1 类，ID `24`。

官方按舰船、飞机、车辆三个大类汇总检测召回率和虚警率，但匹配首先要求细分类别正确。因此，预测框即使覆盖了正确目标，只要把具体舰船类别或飞机型号分错，就不能计为 TP。初赛测试类别与当前 25 个训练类别一致；决赛若增加类别，官方会另行提供相应训练数据。

## 6. 图像文件

### 6.1 格式、通道和位深

| 属性 | 统计 |
|---|---:|
| JPEG | 4,389 |
| PNG | 92 |
| PIL 解码为 RGB | 4,390 |
| PIL 解码为 RGBA | 91 |
| 8-bit 图像 | 4,481 |

91 张 RGBA PNG 的 alpha 通道最小值和最大值均为 255，即完全不透明。通用读取接口可对所有图像执行 `convert("RGB")`，统一得到 `H×W×3` 的 8-bit RGB 数据。

“官方成像模态”与“文件存储通道数”是两个不同概念：

- 1,341 张舰船图属于全色任务域，文件实际是 RGB JPEG，三个通道数值相同；
- 飞机和车辆属于 RGB 任务域；飞机图中包含 RGB JPEG、RGB PNG 和 RGBA PNG；
- 不能只根据文件扩展名或通道数决定目标大类，应以标签类别映射为准。

### 6.3 文件名形态

图像文件主要表现为两种可直接观察到的命名形态：

- `MAR20_<数字>`：3,073 张，对应飞机图像；
- 文件主名中含 `_crop<编号>`：1,408 张，对应舰船和发射车裁剪图。

文件名用于图像—标签配对和追溯，不是官方提供的场景 ID、传感器 ID 或地理位置标识。当前数据也未统一提供可供训练代码依赖的 CRS、GSD、传感器、轨道等遥感元数据。

## 7. 标注格式

每张图像对应一个同名 `.txt` 文件。标签文件使用 YOLO 水平框格式，每个非空行包含五列：

```text
class_id x_center y_center width height
```

字段含义如下：

| 字段 | 类型 | 含义 |
|---|---|---|
| `class_id` | 整数 | 细分类别 ID，范围 `0–24` |
| `x_center` | 浮点数 | 框中心横坐标除以图像宽度 |
| `y_center` | 浮点数 | 框中心纵坐标除以图像高度 |
| `width` | 浮点数 | 框宽除以图像宽度 |
| `height` | 浮点数 | 框高除以图像高度 |

若图像尺寸为 `W×H`，归一化框为 `(cx, cy, bw, bh)`，则像素坐标的半开区间水平框为：

```text
x1 = (cx - bw / 2) * W
y1 = (cy - bh / 2) * H
x2 = (cx + bw / 2) * W
y2 = (cy + bh / 2) * H
```

框宽和框高为：

```text
box_width  = x2 - x1
box_height = y2 - y1
```

转换时保留浮点数，不添加 `+1`，也不应在训练数据解析阶段提前取整。可视化或裁剪前再按具体图像库的边界规则处理。

## 9. 训练集与正式测评数据的关系

当前收到的是训练数据，不包含官方验证样本。官方答复要求现阶段自行划分验证集；正式测评数据中会包含 10,000×10,000 大图。测试图像的成像类型与对应类别的训练图像一致，即舰船使用全色域，飞机和车辆使用 RGB 域。

官方允许使用外部训练数据。若使用外部数据，其类别 ID、许可来源和训练范围需在项目内单独记录，不能与上述官方原始数量混写。

## 10. 评测规则

三个大类分别统计：

```text
Recall = TP / (TP + FN)
FDR    = FP / (FP + TP)
```

- 舰船和飞机使用 IoU `0.50`；车辆使用 IoU `0.35`。
- 匹配要求预测细类与真值细类相同。
- 预测按置信度从高到低参与匹配，一个真值最多匹配一个预测。
- 未匹配预测计为 FP，未匹配真值计为 FN；对同一目标的重复预测不能重复记为 TP。
- 正式评测包含各大类 Recall、各大类 FDR 和总时效性排名。
- 10,000×10,000 单幅图像从读取完成到输出结果的时间要求不超过 20 秒；硬件参考 RTX 3090 或等效算力，最终环境等待官方统一。
- 最终预测结果为标准 COCO 检测 JSON；正式测试集的图像 ID 对应和提交入口以官方发布接口为准。

## 11. 数据使用边界

官方数据仅供参赛团队在比赛期间训练、验证和测试使用。文档、代码和汇总统计可以在项目内部传递；原始图像、原始标签及能够替代原始数据的大规模派生内容不应公开发布。
