# dev_v1 数据划分报告

## 结论

`dev_v1` 已按固定种子 42 冻结为 3584 张训练图和 897 张验证图，验证集占
20.02%。全部 25 个细类在 train/val 两侧都有正样本；3268 个同源组中没有任何组
跨越 train/val。划分只生成 JSON 清单，没有移动、复制或修改原始图像与标签。

训练集有 16747 个框，验证集有 4186 个框，总计 20933 个框。

## 防泄漏与分层规则

1. 舰船 CCD/PAN 裁剪按裁剪前的卫星产品号分组，同一产品的 tile 绑定到同一侧；
2. FSC 车辆按经纬度点位分组，Bing/Google/Yandex 等不同地图源绑定到同一侧；
3. MAR20 文件名不含可恢复的上游大图或架次信息，因此按单图分组；
4. 图像 SHA-256 完全相同的样本强制合并；本数据中未发现字节级完全重复图；
5. 在舰船、飞机、车辆三个域内分别进行稀有类优先的多标签分层，再合并结果；
6. 目标同时约束验证图像数、各细类正样本图数、实例数和三大域图像数。

本规则处理了文件名可识别的强同源关系和字节级重复，但不把“外观相似”自动视为
重复，以免将相似飞机或舰船误合并。若后续获得 MAR20 原始场景/架次元数据，应生成
新版本划分，不能静默改写 `dev_v1`。

```bash
python scripts/create_split.py \
  --data-root /path/to/data \
  --output data/splits/dev_v1.json \
  --version dev_v1 \
  --data-version official_raw_v1 \
  --val-ratio 0.2 \
  --seed 42
```
