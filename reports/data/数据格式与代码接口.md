# XH-202625 数据格式与代码接口

本文给出读取当前原始数据所需的确定性接口。代码只依赖 `data/` 的目录和文件内容，不依赖额外 CSV、重命名副本或手工类别目录。可执行实现位于 [code/README.md](code/README.md)，下文代码用于解释同一接口；成员实际开发时应直接复用 `code/xh_dataset.py`，不要另写一套标签解析和坐标转换。

## 1. 路径契约

原始数据根目录记为 `DATA_ROOT`：

```text
DATA_ROOT/
├── dataset.yaml
├── readme.md
├── images/{train,val}/
└── labels/{train,val}/
```

当前只有 `train` 有数据。对任意图像：

```text
DATA_ROOT/images/<split>/<stem>.<jpg|jpeg|png>
```

其标签路径为：

```text
DATA_ROOT/labels/<split>/<stem>.txt
```

配对键是 `(split, stem)`，而不是图像在目录中的遍历顺序。遍历前应排序，保证不同机器得到一致顺序。

## 2. 类别契约

原始 ID 必须保持 `0–24`，不要转换为 `1–25`。

## 3. 图像读取

当前文件包含 JPEG 和 PNG，PIL 解码模式包含 RGB 和 RGBA。统一三通道接口可以写为：

```python
from pathlib import Path
import numpy as np
from PIL import Image

def load_rgb(path: Path) -> np.ndarray:
    with Image.open(path) as image:
        image.load()
        rgb = image.convert("RGB")
        array = np.asarray(rgb, dtype=np.uint8)
    assert array.ndim == 3 and array.shape[2] == 3
    return array
```

这会保留 RGB 图的颜色，将 RGBA 图去掉完全不透明的 alpha 通道，并将以 RGB 文件存储的全色舰船图保持为三个相同通道。类别模态应由标签类别映射决定，不应通过“通道是否相同”反推类别。

如果训练框架使用 OpenCV，需注意 `cv2.imread` 默认输出 BGR；在与 RGB 模型接口衔接时显式执行：

```python
image_rgb = cv2.cvtColor(image_bgr, cv2.COLOR_BGR2RGB)
```

图像尺寸始终从文件读取：

```python
height, width = image_rgb.shape[:2]
```

不能假定所有图像均为 800×800。

## 4. YOLO 标签解析与坐标转换

### 4.1 数据结构

建议在内存中用浮点像素 `xyxy` 作为统一框表示：

```python
from dataclasses import dataclass

@dataclass(frozen=True)
class ObjectRecord:
    class_id: int
    xyxy: tuple[float, float, float, float]

@dataclass(frozen=True)
class ImageRecord:
    split: str
    stem: str
    image_path: str
    label_path: str
    width: int
    height: int
    objects: tuple[ObjectRecord, ...]
```

### 4.2 数学定义

输入 YOLO 行：

```text
class_id cx cy bw bh
```

其中 `cx, cy, bw, bh` 都是归一化量。对宽 `W`、高 `H` 的图像：

```python
def yolo_to_xyxy(cx: float, cy: float, bw: float, bh: float,
                 width: int, height: int) -> tuple[float, float, float, float]:
    x1 = (cx - bw / 2.0) * width
    y1 = (cy - bh / 2.0) * height
    x2 = (cx + bw / 2.0) * width
    y2 = (cy + bh / 2.0) * height
    return x1, y1, x2, y2

def xyxy_to_yolo(x1: float, y1: float, x2: float, y2: float,
                 width: int, height: int) -> tuple[float, float, float, float]:
    cx = ((x1 + x2) / 2.0) / width
    cy = ((y1 + y2) / 2.0) / height
    bw = (x2 - x1) / width
    bh = (y2 - y1) / height
    return cx, cy, bw, bh
```

坐标采用连续浮点几何，不使用整数像素的闭区间 `+1` 规则。模型输入变换、裁剪或缩放后，回映射也应先保持浮点数，最终输出时再按提交格式处理。

### 4.3 标签解析器

```python
from pathlib import Path

def read_yolo_label(label_path: Path, width: int, height: int) -> list[ObjectRecord]:
    objects: list[ObjectRecord] = []
    text = label_path.read_text(encoding="utf-8").strip()
    if not text:
        return objects

    for line_no, line in enumerate(text.splitlines(), start=1):
        parts = line.split()
        if len(parts) != 5:
            raise ValueError(f"{label_path}:{line_no}: expected 5 columns")

        class_text, cx_text, cy_text, bw_text, bh_text = parts
        class_id = int(class_text)
        cx, cy, bw, bh = map(float, (cx_text, cy_text, bw_text, bh_text))

        if not 0 <= class_id < len(FINE_NAMES):
            raise ValueError(f"{label_path}:{line_no}: invalid class {class_id}")
        if bw <= 0.0 or bh <= 0.0:
            raise ValueError(f"{label_path}:{line_no}: non-positive box size")

        xyxy = yolo_to_xyxy(cx, cy, bw, bh, width, height)
        objects.append(ObjectRecord(class_id=class_id, xyxy=xyxy))

    return objects
```

解析器不应在读取时对坐标取整。若图像库的裁剪函数要求整数，可在裁剪调用前执行边界裁切和明确的 `floor/ceil`，但不要覆盖训练标注的原始浮点值。

## 5. 完整数据发现代码

下面的代码可直接构造全部训练记录，并同时检查一图一标签的基本契约。

```python
from pathlib import Path
from PIL import Image

IMAGE_SUFFIXES = {".jpg", ".jpeg", ".png"}

def discover_images(image_dir: Path) -> list[Path]:
    return sorted(
        path for path in image_dir.iterdir()
        if path.is_file() and path.suffix.lower() in IMAGE_SUFFIXES
    )

def build_records(data_root: Path, split: str = "train") -> list[ImageRecord]:
    image_dir = data_root / "images" / split
    label_dir = data_root / "labels" / split
    image_paths = discover_images(image_dir)

    image_by_stem: dict[str, Path] = {}
    for image_path in image_paths:
        if image_path.stem in image_by_stem:
            raise ValueError(f"duplicate image stem: {image_path.stem}")
        image_by_stem[image_path.stem] = image_path

    label_paths = sorted(label_dir.glob("*.txt"))
    label_by_stem = {path.stem: path for path in label_paths}

    missing_labels = sorted(set(image_by_stem) - set(label_by_stem))
    orphan_labels = sorted(set(label_by_stem) - set(image_by_stem))
    if missing_labels or orphan_labels:
        raise ValueError(
            f"pairing failed: missing_labels={missing_labels[:5]}, "
            f"orphan_labels={orphan_labels[:5]}"
        )

    records: list[ImageRecord] = []
    for stem in sorted(image_by_stem):
        image_path = image_by_stem[stem]
        label_path = label_by_stem[stem]
        with Image.open(image_path) as image:
            width, height = image.size
        objects = tuple(read_yolo_label(label_path, width, height))
        records.append(ImageRecord(
            split=split,
            stem=stem,
            image_path=str(image_path),
            label_path=str(label_path),
            width=width,
            height=height,
            objects=objects,
        ))
    return records

DATA_ROOT = Path("data")
train_records = build_records(DATA_ROOT, "train")

assert len(train_records) == 4481
assert sum(len(record.objects) for record in train_records) == 20933
assert {obj.class_id for record in train_records for obj in record.objects} == set(range(25))
```

在本项目根目录执行时 `Path("data")` 即为正确相对路径；在其他工作目录执行时应传入 `data/` 的绝对路径。

## 6. 模型数据接口

训练框架通常需要以下字段：

```python
sample = {
    "image": image_rgb,                 # np.uint8, H×W×3
    "boxes": boxes_xyxy,               # float32, N×4
    "labels": fine_class_ids,           # int64, N，范围0–24
    "image_size": (height, width),
    "image_key": (split, stem),
}
```

模型类别数设为 25。若框架把背景作为显式类别，其内部标签偏移只应存在于适配层；保存预测和计算官方指标时必须恢复官方 ID `0–24`。

图像缩放、填充或裁剪时，应同时对 `boxes_xyxy` 执行同一几何变换，并保存逆变换参数，使预测框能够回到原图坐标。

## 7. COCO 坐标与输出

COCO 检测框使用：

```text
[x_min, y_min, width, height]
```

从浮点 `xyxy` 转换：

```python
def xyxy_to_coco(x1: float, y1: float, x2: float, y2: float) -> list[float]:
    return [x1, y1, x2 - x1, y2 - y1]
```

常规 COCO 检测结果是一个 JSON 数组，每个预测对象包含：

```json
{
  "image_id": 123,
  "category_id": 19,
  "bbox": [100.5, 80.25, 92.0, 88.0],
  "score": 0.91
}
```

字段约束：

- `bbox` 是原图像素坐标，不是归一化坐标；
- `bbox[2]`、`bbox[3]` 是宽、高，不是右下角坐标；
- `category_id` 保留预测的细类 ID；
- `score` 是用于排序的置信度；
- `image_id` 必须使用正式测评接口分配的值。当前训练文件名不能替代官方尚未发布的测试图像 ID 规则。

训练阶段若生成完整 COCO 标注，`categories` 可使用 `id=0–24` 与 `dataset.yaml` 同步；若所用第三方库强制从 1 开始，应在适配层维护双向映射，不能把库内 ID 直接写回官方结果。

## 8. 评测匹配接口

对每个大类分别累计 TP、FP、FN，但候选匹配必须比较细类：

1. 将预测按 `score` 从高到低排序；
2. 对当前预测，只考虑同图像、同 `class_id`、尚未匹配的真值；
3. 由该 `class_id` 映射出大类及 IoU 阈值；
4. 若最高 IoU 达到阈值，则预测记为 TP，并锁定该真值；
5. 否则预测记为 FP；
6. 处理完预测后，未匹配真值记为 FN；
7. 按大类计算 `Recall=TP/(TP+FN)` 和 `FDR=FP/(FP+TP)`。

一个真值最多产生一个 TP。对同一目标的后续重复预测因为真值已经锁定，将计为 FP。用于最终复现的内部评估器还需与官方后续提供的完整评测脚本核对置信度截断、并列分数和汇总细节。

## 9. 建议保留的最小运行检查

每次更换机器、解压数据或接入新的训练代码后，至少检查：

```python
assert len(train_records) == 4481
assert sum(len(r.objects) for r in train_records) == 20933
assert all(r.width > 0 and r.height > 0 for r in train_records)
assert all(len(r.objects) >= 1 for r in train_records)
assert all(0 <= o.class_id <= 24 for r in train_records for o in r.objects)
assert all(
    o.xyxy[2] > o.xyxy[0] and o.xyxy[3] > o.xyxy[1]
    for r in train_records for o in r.objects
)
```

验证集由使用者从 `train_records` 中划分；不要把空的官方 `images/val` 当作可评估数据，也不要把自行划分的验证统计写成官方验证集统计。
