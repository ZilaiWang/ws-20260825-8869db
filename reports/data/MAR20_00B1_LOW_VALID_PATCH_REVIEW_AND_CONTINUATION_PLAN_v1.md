# MAR20 00B1 低背景支持复核与续跑方案 v1

## 1. 结论

`00B` 的 `fail_low_valid_patch_fraction` 保持为不可改写的原始科学记录。全量缓存技术完整，失败由 19/3,842 个极端密集或大目标节点触发，而不是坐标、掩码、DINO、分片或有限性错误。

本轮不降低 15% 飞机框外扩，不改变 20% patch 前景占比阈值，不重新提取相同特征。25% 从“任一节点触发全局失败”修订为节点级背景支持质量标志；修订只允许继续无监督 VLAD 和候选发现，不授予自动成边或正式分组权限。

120图 patch audit 的原始自动门禁实际为 `fail`，不能写成“通过”：主工作点只有 `mar20:1074` 低于25%；`1594/1749` 仅在非主工作点20%外扩下略低于25%。

## 3. 00B1 修订合同

### 3.1 保持不变

- 原始 extraction/patch-audit summary 只读；
- 外扩 `r=0.15`；
- patch 前景面积超过20%即删除；
- DINOv2-B/14 block 9/10/11及四旋转；
- 每图0°等额抽16个有效patch；
- 所有描述子和几何分数仍不能直接 union。

### 3.2 质量分层

| 质量层 | 条件 | 下游合同 |
|---|---|---|
| normal | `valid_fraction ≥ 0.25` | 按常规候选处理 |
| low | `0.10 ≤ valid_fraction < 0.25` | 必须额外证据 |
| very-low | `<0.10` | 必须额外证据，默认倾向单例/隔离 |

继续VLAD的必要条件：

1. 原始状态严格等于 `fail_low_valid_patch_fraction`；
2. 缓存指纹、index SHA、行数、旋转、节点集合和有限性全部一致；
3. 每个节点有效patch不少于原合同要求的16个抽样；
4. 低背景节点不超过全库1%；
5. 120图audit在15%主工作点低背景比例不超过1%；
6. patch audit 的自动失败只能来自 `valid_patch_fraction`，不得包含几何错位或其他错误。

这是看过结果后的显式协议修订，因此产物必须同时记录原始失败和修订准入，不称为预注册门禁通过。

### 3.3 低背景节点的最终限制

低背景节点可以参加候选召回，以免遗漏精确重复或真实重叠；但不能仅凭DINO/VLAD相似度形成group edge。只有精确像素、可信pHash近重复、掩码外SIFT/RANSAC或人工严格正例才能支持连接，否则进入保守单例或fold-specific embargo。

## 4. 续跑路径

1. 在服务器现有大缓存上执行00B1复核器；
2. 生成全库质量表、19节点清单、原始失败到续跑准入的审计JSON；
3. 生成新的、带来源失败字段的 admitted summary，原文件不动；
4. 使用现有 patch samples 拟合 PCA128 + VLAD16/32；
5. 第二遍提取 VLAD、PCA-whiten-512；
6. 多路候选、pHash、精确像素和掩码外SIFT/RANSAC；
7. 生成240对+10%重复盲评包；
8. 正常停在人工审核，不生成group ID/CV3。
