# 数据集简报

当前收到的是仅含训练标注、25 个细类、三大类极不平衡的遥感裁剪图数据集；没有官方验证样本，也没有 10000×10000 大图。

## 数据规模

| 项目 | 数量 |
|---|---:|
| 可解码图像 | 4481 |
| 有效 YOLO 框 | 20933 |
| train / val 图像 | 4481 / 0 |
| 纯背景图 | 0 |
| 损坏图 | 0 |

| 大类 | 实例 | 正样本图 | 数据细类 ID |
|---|---:|---:|---|
| 舰船 | 2682 | 1341 | 0–3 |
| 飞机 | 17849 | 3073 | 4–23 |
| 车辆 | 402 | 67 | 24 |

细类最大/最小实例比为 126.29:1。图像尺寸范围为 423–1384 × 355–1228；没有可靠的 GSD、CRS、传感器或轨道元数据。

## 直接结论

1. 官方 val/test 不可见，内部验证必须自建，且可能与闭测域不同。
2. 不应做随机图像级划分；先核验文件名推断的场景组和 11 组近重复候选。
3. 车辆只有 402 个实例、67 张正样本图，需要单独监控 Recall/FDR。
4. 训练集没有纯背景图，FDR 校准缺少直接负样本证据。
5. 没有 10K 大图，切片尺寸和 20 秒约束必须在后续大图或压力测试中验证。

## 第一轮建议

核验现有候选划分后，冻结约 3581 张训练图 / 900 张验证图的 group-aware manifest，并用三个 group-aware folds 检查稀有类稳定性。随后依次完成：可复现基线、官方评估、COCO JSON 校验、稀有类分层指标、切片回映射和 3090 等效设备测速。
