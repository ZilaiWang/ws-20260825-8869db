# XH-202625 项目现状审计（2026-07-19）

## 结论

仓库此前已完成数据和评测基础设施，但模型训练、真实推理、跨切片融合和测速仍是
占位实现，尚不能产生基线结果。本轮已把模型侧补成可执行闭环，并新增项目自研 HPR
细粒度原型分支；`dev_v1` 已按同源组冻结，真实精度实验仍需完成模型环境与训练，
`cv3` 仍待生成。

## 题目要求对齐

| 要求 | 已知约束 | 当前状态 |
|---|---|---|
| 25 细类检测 | 细类和位置都正确才算 TP | 官方细类匹配评测已有测试 |

| 三类汇总 | 舰船/飞机 IoU 0.50，车辆 0.35 | `project.yaml` 为唯一规则源 |
| 标准提交 | 25 类 COCO detection JSON | 校验、导出和统一 adapter 已完成 |

## 本轮开始前已有内容

- 数据审计报告：4,481 张、20,933 框、25 类分布、尺寸和模态统计；
- `XHDataset`：YOLO 标签读取、RGB 统一、COCO 导出和 PyTorch 轻量适配；
- 官方 Recall/FDR：细类降序贪心匹配、重复框 FP、三大类不同 IoU；
- 公共契约：稳定 image ID、`InferenceSample`/`Prediction` 和 COCO 交付格式；
- 滑窗坐标生成、坐标变换、预测校验及 85 项基础测试。

当时的关键缺口：

- `trainer.py`、`infer.py`、`benchmark.py` 只返回“未实现”；
- 只有 DummyDetector，没有真实检测器 adapter；
- NMS、跨 tile 融合均抛出 `NotImplementedError`；
- 没有 M1/M2/M3 可复现配置，也没有针对长尾小样本的可执行方法；
- `dev_v1`、`cv3` 和真实 10K 图当时仍缺失。

## 不能宣称已完成的事项

1. `dev_v1` 已冻结但尚未完成真实训练，仍不能给出模型 Recall/FDR；
2. 已有 PyTorch 2.5.1/CUDA 12.1，但尚未安装 Ultralytics，也没有训练权重；
3. 没有 RTX 3090 实测，不能声称满足 20 秒；
4. 没有纯背景训练图，当前 FDR 在闭测域上的可靠性未知；
5. 分层大类 NMS 和三个工作阈值是待消融参数，不能未经 dev 验证直接用于提交。

下一步唯一正确顺序是：M1 dry-run → M1 A0/A1/A2 → 阈值曲线
和错误分析 → 10K 测速 → 再决定是否投入 M2/M3。
