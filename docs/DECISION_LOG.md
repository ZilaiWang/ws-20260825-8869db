## 2026-07-14

### 决策 1：采用模型无关的 src 结构

- **背景**: 项目初期，尚未确定最终检测器。
- **候选方案**:
  - A. 绑定特定框架（如 MMDetection）
  - B. 自己从头写训练框架
  - C. 使用抽象接口 + 注册表，模型无关
- **选择**: C
- **理由**: 不锁定具体模型，允许灵活试错；接口足够简单，team 成员容易理解。
- **影响**: `src/rsdet/models/base.py` 定义抽象类，`registry.py` 实现注册机制。
- **负责人**: 王子莱
- **可逆**: 是（后续可改为框架集成）
